# MEGA WAR 8.6 — Cliente

Tibia 8.60 con mapa global, PVP Enforced. Entra con un personaje nivel 150, mata a otros jugadores y sube de nivel. Al salir, todo vuelve a empezar.

**Web e instrucciones:** https://mega-war.com

## Jugar
- **En el navegador (sin instalar):** https://mega-war.com/jugar/
- **Windows:** [MEGA_WAR_8.6_windows.zip](https://github.com/skyspablo/mega-war-client/releases/latest/download/MEGA_WAR_8.6_windows.zip)
- **macOS (Apple Silicon):** [MEGA_WAR_8.6_mac.zip](https://github.com/skyspablo/mega-war-client/releases/latest/download/MEGA_WAR_8.6_mac.zip) — en Mac Intel, juega desde el navegador.
- **Linux:** [MEGA_WAR_8.6_linux.zip](https://github.com/skyspablo/mega-war-client/releases/latest/download/MEGA_WAR_8.6_linux.zip)

Cuenta: `war` / `war`.

El cliente es [OTClient](https://github.com/opentibiabr/otclient) (opentibiabr, licencia MIT) configurado para MEGA WAR.
